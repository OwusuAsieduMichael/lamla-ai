# KNUST expansion

The web pilot stays inside BSc Computer Science until authorized materials and grounded answers are proven.

## After the pilot

Expansion can widen one axis at a time:

1. More Computer Science courses, only from official records
2. Other departments in the Faculty of Physical and Computational Sciences
3. Other faculties in the College of Science
4. Other KNUST colleges

Each step still requires authorization, attribution, ingestion, and retrieval. Do not copy a course list from memory into the database.

## What stays the same

- Text, voice, and image share one academic engine
- Students see only approved, granted sources
- Missing keys or missing sources produce a refusal
- A mobile app waits until the web pilot is validated
